# 二項分布と正規分布 — 確率の実験室

二項分布 B(n, p) が正規分布 N(np, np(1−p)) に近づく様子を観察する、日本語の教育用Webアプリです。HTML・CSS・JavaScriptのみで動作し、外部ライブラリ、ビルド、インストールは不要です。アプリは通信なしでも操作できます。ページ読み込み時にアクセス記録の通信を1回だけ行います。

## 起動

このフォルダーの **index.html をブラウザーで開く**だけで利用できます。`style.css` と `script.js` は同じフォルダーに置いてください。PC・iPad・スマートフォンの画面幅に対応しています。iPadでは、GitHub Pagesで公開したURLをSafariで開く方法が便利です。

## 画面配置

n・pの操作パネルの直下にヒストグラムを配置しています。タイトル、操作部、表示切替、凡例の余白を抑え、PCとiPadでスライダーを動かしながら分布を観察できます。再生・一時停止・リセット・速度設定はグラフの見出し付近、平均・分散・標準偏差と確率分布表はグラフの下にあります。グラフの高さは画面の高さに合わせて調整します。

レイアウト更新時に1366×768、1280×720、1024×768、768×1024でスライダーとグラフ全体が同時に見えることを確認しました。390×844でも横はみ出しがないことを確認しています。スライダー変更、標準化、再生・一時停止・リセットの連動を再確認し、`script.js` は変更していません。

## 操作

- **n / p**：スライダーまたは数値入力で変更します。n は 1〜1000 の整数、p は 0.01〜0.99。n のプリセットも利用できます。入力途中の空欄や範囲外の値は計算に反映せず、入力確定時に許容範囲へ調整します。
- **グラフ**：青い棒が二項確率、赤い曲線が対応する正規密度です。「平均周辺」「全範囲」で切り替え、最小値と最大値を入力して任意の範囲にもできます。範囲外の棒を合算・集約することはありません。
- **選択**：棒、表の列、または成功回数 k の数値入力で選択します。グラフにフォーカスした状態の左右矢印キーでも変更できます。表の k ボタン上でも左右矢印キーが使えます。選択値はグラフ・表・詳細欄で連動します。表で範囲外の k を選択すると、その位置が見えるようグラフの表示範囲が移動します。
- **正規曲線 / 連続補正**：それぞれ独立して表示・非表示にできます。連続補正は、選択した k に対する区間 [k−0.5, k+0.5] の正規曲線の下面積です。
- **標準化表示**：横軸 z = (k−μ)/σ、棒の幅 1/σ、高さ P(X=k)σ に切り替えます。曲線は標準正規密度。棒の面積は元の確率を保ちます。初期範囲 −4〜4 は n や p を変更しても固定します。全範囲・任意範囲にも切り替えられます。
- **分布表**：k = 0〜n のすべての列を保持します。横スクロールに対応し、平均に最も近い列を初期選択して中央に表示します。4桁 / 6桁に切り替え可能です。「選択列へ移動」で現在の列に戻れます。詳細欄ではさらに多い桁数で表示し、小さい値には指数表記を使います。
- **アニメーション**：初回の再生は n = 10 から200まで1ずつ増加します。一時停止後の再生は続きから、200到達後は10から再開します。2 / 10 / 30 回毎秒で速度変更できます。再生中は p 入力を固定します。n の手動変更は再生を停止します。「リセット」は p と表示モードを保って n = 10 に戻します。タブを離れると自動で一時停止します。
- **PNG保存**：白背景の 1600×760 px のPNGを生成します。タイトル、表示モード、n、p、平均、標準偏差、選択 k、表示中の凡例を含みます。現在の横軸範囲と表示設定を反映します。端末のダウンロードまたは共有機能で保存してください。

## アクセス記録

既存のタイリング確認アプリと同じGASへ、ページ読み込みごとに `app=binomial-normal` をGETで1回送信します。再読み込みでは新たに1回送信します。n・pの変更、スライダー、アニメーション、表示切替、表の選択、PNG保存では送信しません。

送信設定は `mode: no-cors`、`cache: no-store`、`credentials: omit`、`keepalive: true` です。応答を待たず、再送は行いません。非同期の通信失敗、同期例外、fetch非対応時も画面へのエラー・通知表示は行わず、操作を継続できます。n・pなどの操作内容は送信しません。`no-cors`のため、アプリからGAS側の記録成功は判定しません。

回帰テストは `node tests/access-log.test.mjs` で実行できます（テスト実行時のみNode.jsが必要）。実際のアプリ初期化とイベント処理を模擬DOM上で実行し、fetchを差し替えて送信回数と失敗時の動作を検証します。本番GASへテスト通信は送りません。

## 数学と数値計算

### 二項確率

最頻値 m = floor((n+1)p) で相対重みを1とし、左右に漸化式を適用します。

```
w[k−1] = w[k] × k/(n−k+1) × (1−p)/p
w[k+1] = w[k] × (n−k)/(k+1) × p/(1−p)
P(X=k) = w[k] / Σw
```

階乗を直接計算せず、最大の重みから外側へ計算するためオーバーフローを避けられます。合計には補償和を使用し、正規化後の総和も画面に表示します。JavaScriptの倍精度で表現できない極端に小さい裾の値（おおむね 10⁻³²⁴ 未満）は0になります。表の丸めによる0と、数学的に確率が0であることは異なります。

### 正規近似と連続補正

μ = np、σ² = np(1−p) として、各 k の近似値は

```
P(k−0.5 ≤ Y ≤ k+0.5)
= Φ((k+0.5−μ)/σ) − Φ((k−0.5−μ)/σ)
```

で求めます。CDFは不完全ガンマ関数の級数と連分数で計算します。裾では上側確率の差を利用し、1に近いCDF同士の減算による桁落ちを避けます。k = 0、n でも指定どおり幅1の区間を使い、近似値の再正規化や端点への裾の集約は行いません。このため正規近似値の全列の和は、特に歪んだ分布では1未満になります。

np と n(1−p) は近似の妥当性を考える指標です。両方10以上という表示は授業で比較するための目安で、誤差の保証ではありません。

通常表示の縦軸では、幅1の棒の確率と正規曲線の密度を重ねています。標準化表示の縦軸は密度に揃えています。全範囲表示で棒が画素より細くなっても、整数ごとに個別描画し、列や確率をまとめません。

| 20 | 0.5 | 10 | 0.1761970520 | 0.1769367262 |

- 上記6条件に加え (1000, 0.99)、(1, 0.01)、(1, 0.99) で、非負性・総和・平均・分散を検証。総和の1からの差は 10⁻¹² 未満。参照確率との最大絶対差は 10⁻¹³ 未満でした。
- 標準正規CDFを z = 0, ±1, ±1.96, ±4, ±8, ±10 でPythonの `math.erfc` と比較し、最大絶対差は約 1.1×10⁻¹⁶ でした。
- ブラウザーで指定6条件と p = 0.99 の画面更新、n+1列、総和、表とグラフの選択連動、矢印キー、表示桁数、曲線と連続補正の切替を確認しました。
- 標準化の −4〜4 固定、全1001本を含む全範囲、任意範囲の入力検証を確認しました。
- 通常表示で再生・一時停止・リセット、標準化表示で200までの再生と停止、p入力固定を確認しました。
- PNGを実際にダウンロードし、1600×760 px、タイトル・統計量・凡例・標準化グラフ・連続補正と白背景を確認しました。

### 授業前の手動チェック

1. 上の6条件を順に設定し、平均付近のかたちと総和を確認します。
2. 棒と表の列をそれぞれ選び、k・ハイライト・詳細の値が一致することを確認します。
3. 連続補正を切り替え、選択区間の面積を比較します。
4. 標準化し、nを増やしても横軸が −4〜4 のまま変わらないことを確認します。
5. 再生・一時停止・リセット・速度を操作します。
6. PNGを保存し、授業で利用する端末の保存先から画像を開きます。
